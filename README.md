# Маршруты — КМЗ №1

Приложение для водителей: список точек по маршрутам, адреса, фото витрин, заметки, построение маршрута в Яндекс.Картах, отметки о доставке.

Работает в браузере телефона, ставится на домашний экран, открывается без интернета.

---

## Два способа запустить

Приложение само определяет, где оно работает, и подстраивается.

### 1. Netlify (полная версия) — рекомендуется

Работает всё: правка маршрутов прямо на сайте, загрузка фото, ссылки водителям с ограничением доступа, отметки доставки, видимые вам.

Разово:

1. Загрузите этот репозиторий на GitHub.
2. На netlify.com: **Add new project → Import an existing project → GitHub** → выберите репозиторий.
3. Build command оставьте пустым, Publish directory — точка (`.`).
4. **Site configuration → Environment variables → Add**: имя `ADMIN_PASS`, значение — ваш пароль редактирования.
5. **Deploys → Trigger deploy**.

Дальше любое изменение в репозитории публикуется само.

### 2. GitHub Pages (режим просмотра) — бесплатно и без ограничений

Серверных функций там нет, поэтому маршруты читаются из файлов `data/route-N.json`.
Водители видят точки, фото, заметки, строят маршрут и отмечают доставку у себя в телефоне. Правка маршрутов недоступна.

1. **Settings → Pages → Source: GitHub Actions**.
2. Push в ветку `main` — сайт публикуется автоматически.
3. Чтобы наполнить данными: в полной версии откройте **⋯ → Выгрузить файлы для GitHub**, положите скачанные `route-1.json` … `route-6.json` в папку `data/` и закоммитьте.

Фото в этом режиме берутся из `data/photos/ИМЯ.jpg`, где ИМЯ — значение поля `photo` у точки.

## Ссылки водителям

Войдите на сайте по паролю (замок в правом верхнем углу), нажмите **🔗**, затем **«Создать защищённые ссылки»**.

Появится семь ссылок:

| Ссылка | Кому | Что открывает |
|---|---|---|
| `/r1.html?k=…` … `/r6.html?k=…` | водителю | только его маршрут |
| `/rall.html?k=…` | вам и руководителю | все маршруты |

По ссылке водителя чужие маршруты не откроются, даже если поправить адрес вручную. Ключ запоминается в телефоне — можно добавить значок на домашний экран, и он будет работать без ссылки.

Кнопка **«Сменить все ключи»** обнуляет старые ссылки. После неё разошлите новые.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: интерфейс и логика |
| `import.html` | перенос точек из Google Keep, массовая привязка фото |
| `netlify/functions/api.mjs` | сервер: маршруты, фото, отметки, ключи доступа |
| `sw.js` | работа без интернета; фото кэшируются навсегда |
| `r1…r6.html`, `rall.html` | страницы-ссылки с превью для мессенджеров |
| `data/route-N.json` | маршруты для режима GitHub Pages |
| `data/photos/` | фото для режима GitHub Pages |

Структура точки:

```json
{
  "id": "k1001",
  "name": "Кутков Ставропольская",
  "addr": "Васюринский, ул. Шевченко 12",
  "phone": "+79181234567",
  "hours": "8:00–20:00",
  "note": "Выгрузка с утра, ключи у продавца",
  "url": "https://yandex.ru/maps/…",
  "url2": "https://2gis.ru/…",
  "lat": 45.035, "lon": 38.975,
  "photo": "abc123"
}
```

Обязательно только `id` и `name`. Координаты нужны для построения маршрута цепочкой; без них кнопка ведёт по ссылке на одну точку.

## Возможности

**Водителю:** список точек по порядку, поиск по фамилии и адресу, фото витрины, заметка, адрес и режим работы, кнопки «Поехали» и «Позвонить», отметка доставки с причиной непоставки, карта всех точек, построение маршрута цепочкой и расчёт кратчайшего пути, работа без связи, светлая и тёмная тема.

**Вам:** правка точек, порядок перетаскиванием, план на день и шаблоны по дням недели, составление маршрута вставкой списка фамилий, массовое выделение и перенос между маршрутами, поиск координат по ссылкам Яндекса и 2ГИС, заполнение телефонов списком, поиск дублей, резервные копии, импорт из Google Keep.

## Обслуживание

- **Резервные копии.** ⋯ → «Копия всех маршрутов». Делайте перед крупными правками.
- **Обновление.** Правки в репозитории публикуются автоматически. На Netlify каждая публикация расходует кредиты бесплатного плана (300 в месяц, около 19 публикаций) — копите изменения и заливайте пачками.
- **Перенос на свой сервер.** Интерфейс переносится как есть. Переписать нужно только `netlify/functions/api.mjs` под ваш сервер: логика та же, меняется способ хранения.

## Ограничения

- Один пароль на всех, без учётных записей и ролей.
- Кто сохранил последним — того и версия; одновременное редактирование двумя людьми не разводится.
- Отметки доставки не подписаны именем водителя.
- Яндекс.Карты принимают не больше 10 точек в одной ссылке — длинные маршруты разбиваются на части автоматически.
- Карта требует интернета; списки и фото работают без него.
